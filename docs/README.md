## 历史资料怎么处理

01–18保留背景、规则及历史证据；19–23保留设计和实现轨迹。所有旧入口和任务Prompt已标记需先读CURRENT，避免重复执行。

旧文档原位保留，以免破坏代码、报告及对话链接。只有旧索引快照进入archive；截图、测试脚本、原型、构建包及工作记录未删除。历史状态中的“未发布”“移动端必须验收”“总选地3分钟”“借港代换”不能覆盖CURRENT和24。
