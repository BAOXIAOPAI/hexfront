# 视觉设计规范

> 版本 v0.1（方向待定） · 2026-11-05
> **本轮不开发，只定方向。**
>
> 参考图：`clipboard-2026-11-05` 奶茶店经营界面（日式/韩式休闲游戏风）

---

## 0. 先划清界限：现在这个原型不是设计稿

`prototype/map.html` 是一次**工程验证**，目的是确认三件事：
- 六边形几何对不对（19/30/37 格，54/80/96 个顶点）
- 数字片、港口、强盗的位置逻辑对不对
- 5-6 人版是不是 30 格

它用最省事的方式画（纯 SVG、基础色块、系统字体），因为任何视觉打磨都会干扰判断。**它的使命已经结束，之后的所有界面都不会沿用它的样子。**

---

## 1. 参考图的「精致」由什么构成

拆开看，它好看不是因为画得复杂，而是因为八条克制的规则：

| # | 配方 | 具体做法 |
|---|---|---|
| 1 | **统一的手绘描边** | 所有元素都有 1.5–2px 描边，颜色是深棕 `#5A4033` 而非纯黑。这一条贡献了最大的"贴纸感" |
| 2 | **暖白底，不是纯白** | 卡片是 `#FFF9F0` 奶油色，像纸像布，久看不刺眼 |
| 3 | **大圆角 + 胶囊** | 卡片 16–20px，按钮 12px，标签全胶囊。整体柔软，没有锐角 |
| 4 | **阴影很浅很散** | 不用重投影，用大模糊 + 低透明度的暖色阴影，只做"浮起 2mm"的暗示 |
| 5 | **低饱和 + 高明度** | 粉彩色系，没有一个纯色。饱和度普遍在 40–60% |
| 6 | **高密度但强分组** | 信息很多，但每个区块都是独立卡片，间距 8–12px，一眼能分出层级 |
| 7 | **圆体标题 + 深棕正文** | 标题用手写感圆体，正文用常规黑体但颜色是深棕。亲和力来自字体不只是颜色 |
| 8 | **装饰填充空白** | 小花、缎带、木纹、小图标。作用不是美化，是让空白区域不显得"空" |

**这八条可以整体迁移。** 它们跟"奶茶店"没有关系，跟"让人觉得舒服"有关系。

---

## 2. 为什么这套结构特别适合卡坦

这是我看完参考图后最想说的一点：

> **参考图的结构是「桌面 + 桌上的卡片 + 场景装饰」。**
> **而卡坦岛本来就是桌游——玩家就是在桌面上玩。**

所以不需要"把桌游做成 App"，而是反过来：**做一个"更好的桌子"。**

- 背景 = 木质桌面（暖棕，有纹理）
- 棋盘 = 放在桌上的一叠六边形板，有厚度、有投影
- 玩家信息 = 桌上的记事卡/便签
- 手牌 = 摊在桌边的资源卡
- 交易 = 递过去的纸条

这个方向既精致，又天然贴合主题，还解决了一个实际问题：**卡坦的界面元素太多（棋盘、手牌、分数、交易、日志），只有"桌面"这种隐喻能自然容纳它们。**

## 3. 视觉方向（需你选）

### 方向 A · 木桌手绘（推荐）

```
背景  暖棕木质桌面 + 边缘的绿植/油灯装饰
棋盘  象牙白底板 + 彩色六边形，每块有手绘纹理（小树、羊、麦穗）
卡片  奶油纸卡，深棕描边，微阴影
字体  霞鹜文楷（标题）+ 思源黑体（正文）
气质  温暖、手作感、像一盒精致的实体桌游
```

**优点**：与卡坦的"自然/开拓"主题最契合；地块本身的六种颜色能自然融入；参考图的质感几乎可以照搬。
**风险**：木纹和插画的工作量最大。

### 方向 B · 糖果卡通风

```
背景  薄荷绿/奶油粉渐变，云朵装饰
棋盘  圆润六边形，糖果色，粗白边
卡片  纯白，彩色描边，立体按钮
字体  站酷快乐体 / 圆体
气质  可爱、轻快、像手机小游戏
```

**优点**：最贴近参考图；AI 生成素材容易统一。
**风险**：卡坦是策略游戏，糖果风会削弱"我在认真经营"的感觉；四种玩家颜色（红蓝白橙）在糖果色背景上容易糊。

### 方向 C · 北欧极简

```
背景  亚麻色/浅灰
棋盘  低饱和大地色，无描边，细线
卡片  纯白，极淡阴影，无描边
字体  思源黑体
气质  MUJI、高级、冷静
```

**优点**：最"高级"，最不容易过时，工作量最小（很少需要插画）。
**风险**：不温暖，和你给的参考图气质相反。

### 方向 D · 羊皮纸史诗

```
背景  做旧羊皮纸，暗角
棋盘  手绘地图风，地块像古地图上的领地
卡片  羊皮纸质感，暗金边框
字体  霞鹜文楷 + 衬线
气质  中世纪、冒险、厚重
```

**优点**：主题最"正统"（卡坦本来就是拓荒题材）。
**风险**：暗色调在屏幕上容易显脏；不适合长时间看。

## 4. 色彩系统（以方向 A 为准）

### 4.1 UI 色

| 用途 | 色值 | 说明 |
|---|---|---|
| 桌面木色（深） | `#A8784E` | 背景主色 |
| 桌面木色（浅） | `#C89B6E` | 高光/纹理 |
| 卡片底 | `#FFF9F0` | 奶油白，**不用纯白** |
| 描边 | `#5A4033` | 深棕，所有描边的统一色 |
| 标题文字 | `#3D2B20` | 比描边更深 |
| 正文文字 | `#5A4033` | 同描边 |
| 弱化文字 | `#9C8574` | 次要信息 |
| 强调橙 | `#F0A03C` | 当前玩家、可操作、警告 |
| 信息蓝 | `#6FB3C9` | 链接、次要按钮 |
| 成功绿 | `#7FA85C` | 确认、获得资源 |
| 危险红 | `#D96A55` | 弃牌、7 点、失去 |

### 4.2 地块色（需降饱和）

标准卡坦的六色偏艳，在木桌上会打架。建议降饱和 15–20%，统一加 `#5A4033` 描边：

| 地块 | 色值 | 建议纹理 |
|---|---|---|
| 森林 | `#4A8B5C` | 三棵小松树剪影 |
| 丘陵 | `#C4704F` | 层叠的砖块/土坡 |
| 牧场 | `#9BC46A` | 几团羊毛 + 草点 |
| 田地 | `#E8B84B` | 麦穗成排 |
| 山脉 | `#9AA0A6` | 三角山脊 + 雪顶 |
| 沙漠 | `#D9C48F` | 沙丘波浪 + 仙人掌 |

### 4.3 玩家色（四人）

必须能在六色地块上都清晰可辨：

| 玩家 | 主色 | 形状辅助 |
|---|---|---|
| 1 | `#D9534F` 朱红 | 圆形屋顶 |
| 2 | `#4A7FBF` 靛蓝 | 尖顶 |
| 3 | `#F0F0EA` 象牙白 | 圆顶 + 深描边 |
| 4 | `#E8A33D` 橙 | 屋顶 + 小旗 |

> ⚠️ 白色玩家在浅色地块上有天然劣势，必须靠**深描边 + 形状差异**补偿，不能只靠颜色。这是无障碍要求（`01-PDR` 第 7 节）。

## 5. 字体

| 用途 | 字体 | 许可 |
|---|---|---|
| 标题 / 玩家名 / 数字 | **霞鹜文楷**（LXGW WenKai） | 免费商用 |
| 正文 / 按钮 / 表单 | **思源黑体**（Source Han Sans） | 免费商用 |
| 拉丁数字 | 霞鹜文楷自带，或 Inter | 免费 |

**为什么不选站酷快乐体**：太幼稚，卡坦有成年玩家，且需要承载"分数""概率"这类严肃信息。
**为什么选霞鹜文楷**：手写楷体，有温度、有书卷气，和"拓荒者记录"的主题吻合，同时不像圆体那样显轻浮。

## 6. 布局（桌面端 16:9 优先）

```
┌───────────────────────────────────────────────────────────────┐
│ 房间号 · 4 个玩家头像 · 当前回合 · 设置                   64px │
├─────────┬─────────────────────────────────────┬───────────────┤
│         │                                     │               │
│ 玩家列  │            棋盘（主舞台）             │   操作区      │
│         │                                     │               │
│ 头像    │      木桌 + 六边形板 + 立体棋子       │  掷骰按钮     │
│ 分数    │                                     │  建造/交易     │
│ 手牌数  │                                     │  结束回合     │
│ 港口    │                                     │               │
│         │                                     │   手牌区      │
│ 240px   │              flex                   │   280px       │
│         │                                     │               │
├─────────┴─────────────────────────────────────┴───────────────┤
│ 交易栏 · 快捷操作 · 消息提示                            88px  │
└───────────────────────────────────────────────────────────────┘
```

**关键决定**：棋盘必须占 55% 以上的面积且不加任何遮挡。所有面板都是"可收起的侧栏"，随时能把棋盘让到全屏。

**为什么不做参考图那种"左右对称三栏"**：参考图是经营游戏，场景是主角；卡坦是棋类，棋盘是主角。左右栏只放必要信息，不抢戏。

## 7. 组件规范

| 组件 | 规格 |
|---|---|
| 卡片 | 圆角 18px，底 `#FFF9F0`，描边 2px `#5A4033`，阴影 `0 4px 12px rgba(90,64,51,.12)` |
| 主按钮 | 高 44px，圆角 14px，橙色渐变，**底部有一条 3px 深色边模拟厚度**，按下时下移 2px |
| 次按钮 | 同尺寸，透明底 + 描边 |
| 数字圆片 | 直径 38px，奶油白底，深棕描边 2px，数字用霞鹜文楷，6/8 用朱红 |
| 资源图标 | 24×24，手绘描边风，与地块纹理同一套画风 |
| 玩家棋子 | 村庄 = 小房子（3.5D 微透视），城市 = 同款加高加旗，道路 = 短木条 |
| 标签/缎带 | 用于分区标题，两端带剪角，浅色底 + 描边 |

**统一的"厚度"语言**：所有可点击元素在底部加 2–3px 深色边，制造实体按键的错觉。这是这类游戏 UI 精致感的关键细节。

## 8. 动效原则

三条规矩：

1. **不超过 400ms**（掷骰的骰子滚动除外，可到 800ms 且可点击跳过）
2. **必须有物理感**：用缓出曲线（`cubic-bezier(.34,1.56,.64,1)` 带轻微回弹），不要线性
3. **不能阻塞操作**：任何动画期间玩家都能点下一步

关键动效：
- 掷骰 → 骰子滚动 → 定格 → 匹配数字的地块**依次**亮起（间隔 60ms）
- 获得资源 → 小卡片从地块飞向左栏头像
- 建造 → 棋子从上方落下 + 一次轻微弹跳
- 回合切换 → 镜头轻微推近新玩家区域，再回正
- 强盗移动 → 带一小段抛物线 + 落地扬尘

## 9. 美术资源策略（这里有个成本判断）

| 方案 | 成本 | 效果 | 建议 |
|---|---|---|---|
| 纯 SVG 手绘 | 高（每块地要画纹理） | 最统一，最可控，文件最小 | 长期最优 |
| AI 生成 PNG | 中（要调一致性） | 容易出彩，但风格难统一 | 做背景/装饰 |
| 混合 | 中 | 地块/棋子用 SVG，装饰用 AI | **推荐** |

**具体建议**：
- **背景的木纹、装饰植物、油灯** → AI 生成一张大图，压缩后铺底
- **六边形地块、数字圆片、棋子** → 纯 SVG，因为要缩放和程序化控制
- **资源图标（木砖羊麦矿）** → 纯 SVG，保证 24px 下清晰
