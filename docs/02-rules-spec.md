## J. 最长路与最大军

### 最长路

| 编号 | 内容 | 来源 |
|---|---|---|
| R-90 | 连续 ≥5 条道路得 2 分 | [官方] |
| R-91 | **计算方式**：在所有玩家各自的连通路网中，求**最长简单路径**（不重复经过同一顶点） | [官方] |
| R-92 | 路径**不能穿过对手的村庄/城市**；穿过自己的村庄/城市是允许的 | [官方] |
| R-93 | 分叉路段取最长的一条分支，不累加 | [官方] |
| R-94 | 同长度时，**先达成者**持有 | [官方] |
| R-95 | 后来者必须**严格更长**才能夺取 | [官方] |
| R-96 | 道路被对手新建的村庄截断后，若最长段不足 5 条，**立即失去 2 分** | [官方] |
| R-97 | 失去后重新计算，可能转由他人持有 | [官方] |

> ⚠️ **R-91/R-92 是隐藏难点。** 最长路的正确算法是"图上的最长简单路径"（NP-hard 一般情况，但卡坦路网度数极低，暴力搜索完全可行），**不是**"数自己有多少条路"。
> 见过太多实现直接数路的总数——那在路网分叉时会算错。

## M. v0.1 未覆盖、需明确排除的规则

为避免"后期才发现没做"，以下规则**确认不在范围内**：

- 任何扩展包地块、海洋、港口变体
- 城市与骑士的资源卡/商品卡/城墙
- 5~6 人扩展的建造阶段
- 事件卡、地形变体
- 自定义地图（v0.1 固定标准 19 格布局，但坐标系统按 R-00~R-04 设计，不堵死后续）
