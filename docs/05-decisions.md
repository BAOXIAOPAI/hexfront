## 三、待确认（还需要你回的）

### 🟡 Q-04 · 选地 3 分钟超时后怎么办

| 选项 | 说明 |
|---|---|
| A | 系统按"相邻资源点数最高"自动放置剩余位置 |
| **B**（我建议） | 两级：先降为每人每次 15 秒，再超时自动放置 |
| C | 就地结束，未放的位置随机放 |

**我的建议：B。** 3 分钟对老玩家够用，但偶尔有人卡住（比如正在语音里激烈谈判）。

**另需确认**：3 分钟是**整个阶段的总时长**（8 次放置），还是每人 3 分钟？

---

### 🟡 Q-02 · 借港的租金怎么结算

| 选项 | 说明 |
|---|---|
| **A**（我建议） | 系统只提供「代换」：资源从借用者扣、产物进借用者，港口所有者 P 确认执行。**租金交给语音，用普通交易另外走** |
| B | 系统代收差价给 P |
| C | 只有 P 手动替人换，无确认流程 |

**我的建议：A。** 租金形式千变万化（资源、口头支票、"下次帮你说句话"），系统化只会限制谈判自由。

---

### 🟡 Q-03 · 借港是否限制兑换次数

场景：P 有 2:1 羊港，C 有 20 张羊。C 能不能借这个港口把 20 张全换掉？

| 选项 | 说明 |
|---|---|
| **A**（我建议） | 不限制 |
| B | 限制单回合次数（如 2 次） |

**我的建议：A。** 这是双方自愿，P 借出去一定换到了好处。

---

### 🟢 Q-06 · 非当前玩家的交易请求，无人处理怎么办

**建议**：回合结束时自动失效，不累积。

### 🟡 D-01（修订） · 交易界面形态

语音谈、网站执行 → 界面应该极简。

| 选项 | 说明 |
|---|---|
| **A**（我建议） | **「当前玩家 = 交易所」**：所有请求集中在他面板上，他挑一个成交。不做挂牌、不做竞价 |
| B | A + 保留挂牌（有人没开语音时兜底） |
| C | 保留 v0.1 的完整竞价方案 |

**我的建议：A。** 语音里已经竞价了，UI 再竞价会出现"语音说好给 A、UI 上被 C 抢掉"的混乱。
