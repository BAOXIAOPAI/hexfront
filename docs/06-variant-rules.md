## 0. 定位修正（重要）

经过你的说明，这个项目的定位需要重写：

> ~~「一个为懂规则的人做的线上卡坦岛」~~
> **「一套以卡坦岛为基础、以信任与谈判为核心机制的社交变体」**

理由：你描述的玩法组合（存牌、借港、口头支票、任意比例、选地抢跑）已经构成一套**独立于官方规则的博弈系统**。它的核心资源不是木头和砖，是**信用**。

这反而是好事——它把项目从「做一个已有产品的复制品」变成了「做一个不存在的东西」。下面第 9 节把这个判断展开。

## 1. 与官方规则的七处实质差异

| # | 差异 | 官方 | 本项目 | 影响 |
|---|---|---|---|---|
| V-1 | 掷骰时机 | 回合开始必须先掷骰 | **回合内自由，位置不限** | 引出「存牌」与「恶意投 7」两个机制 |
| V-2 | 掷骰前可做的动作 | 只能掷骰 | **交易、建造、打发展卡全部可做** | 存牌与恶意投 7 的实现前提 |
| V-3 | 交易发起方 | 仅当前玩家可发起 | **任意玩家可向当前玩家发起** | 交易从「申请-审批」变成「双向对话」 |
| V-4 | 港口使用权 | 仅所有者本人 | **可借用当前玩家的港口** | 港口从建筑变成**可出租资产** |
| V-5 | 银行资源 | 每种 19 张，耗尽不补 | **无限** | 后期资源不枯竭；R-31、R-79 作废 |
| V-6 | 开局选地 | 无时限 | **总时长 3 分钟** | 选地阶段变成高压谈判场 |
| V-7 | 交易承诺 | 规则未涉及 | **允许口头支票，系统不介入、不保障** | 信任成为核心机制，允许毁约 |
| V-8 | 强盗初始位置 | 放回沙漠 | **开局即在沙漠** | 无实质差异 |
| V-9 | 掷 7 弃牌取整与选择权 | **向下取整**（9 张弃 4 张）；弃牌由玩家自选 | **向上取整**（9 张弃 5 张）；弃牌由玩家自选 | 略增 7 的惩罚 |

**未变的部分**：建造规则、资源产出、发展卡、强盗、最长路、最大军、10 分获胜、距离规则——全部按 `02-rules-spec.md` 执行。

## 2. 回合结构（v0.3：单一行动阶段）

```
TURN_START（当前玩家 = P）
        ↓
┌────────────────────────────────────────────┐
│  行动阶段（唯一阶段，动作顺序完全自由）          │
│                                            │
│  ✓ 交易（任意人与 P 交易）                    │
│  ✓ 借 / 出租港口                             │
│  ✓ 建造（路 / 村 / 城）                       │
│  ✓ 打发展卡（每回合限 1 张）                   │
│  ✓ 掷骰 ← 必须发生，但**不限位置**             │
│                                            │
│  唯一硬约束：未掷骰不得结束回合                  │
└────────────────────────────────────────────┘
        ↓ P 宣布结束回合（此时已掷骰）
    TURN_END → 下一位
```

**比 v0.2 的两段式更简单**——不需要 PRE_ROLL / POST_ROLL 两套状态，引擎里只要一个 `hasRolled` 布尔量。

### 2.1 我之前的建议是错的，原因如下

v0.2 我建议「掷骰前禁止建造」，理由是那样会绕过存牌。你选择允许，**我收回那个建议**——因为你的规则产生了两个我没想到的机制，而禁止建造会把它们一起砍掉：

**（1）「恶意投 7」成为可能**

掷骰时机固定时，掷骰是纯运气。时机自由后，它变成了**武器**：

> 看到领先者手里 9 张牌，当前玩家可以故意此刻掷骰——赌 7。

这不需要任何额外规则支持，是 V-1 的免费副产品。但如果禁止掷骰前建造，玩家必须先处理完手牌才敢掷，"突然性"就消失了，这个机制也就不存在了。

**（2）存牌从「唯一解」变成「三选一」**

玩家处理多余手牌有三条路：

| 方式 | 好处 | 代价 |
|---|---|---|
| **建造** | 资源变建筑，永久收益 | 资源不够时用不上；且要有合法位置 |
| **存给别人** | 资源完整保留 | 对方可能不还（信任风险） |
| **硬扛** | 零成本 | 掷 7 就弃一半 |

三条路各有代价，决策深度比「只有存牌一条路」高得多。**你的选择更好。**

### 2.2 发展卡同步放开

既然不规定顺位，发展卡也能在掷骰前打。由此产生的战术：

- **先打骑士移走强盗 → 再掷骰**：让被压住的地块恢复产出
- **先打垄断收资源 → 再掷骰**：收来的资源立刻可用于建造
- **先打筑路占点位 → 再掷骰**：抢在别人之前占位置

### 2.3 但有一条必须保留

**「当回合购买的发展卡不能当回合打出」仍然生效。**

否则「买卡 → 立刻打骑士 → 移强盗 → 掷骰」能在一回合内闭环，节奏会失控。这是官方规则，也是必要的限制。

## 3. 存牌机制

### 3.1 机制

因为 V-1 + V-2，玩家可以在掷骰之前转移手牌：

```
玩家 A 的回合，A 手里 11 张牌
→ 若现在掷骰掷出 7，A 要弃 5 张
→ A 先把牌转给 B、C、D
→ A 降到 6 张再掷骰，即使 7 也无损
→ 掷骰后，牌再还回来（或按约定分红）
```

### 3.2 关键洞察：自己回合与别人回合，难度天差地别

这是 V-1~V-3 组合出来、我在 v0.2 没看出来的东西：

| 场景 | 可交易对象 | 分散能力 |
|---|---|---|
| **自己的回合** | B、C、D **三人** | 可分散给三人，每人都不超 8 张 |
| **别人的回合** | **只有当前玩家 P** | 只能存给一个人，P 一接就可能自己超限 |

**推论一**：聪明的玩家必须在**自己的回合**就把手牌处理好。指望别人回合救你，只能祈祷当前玩家愿意接、且接得住。

**推论二（更狠）**：在别人的回合你**来不及反应**——P 随时可能掷骰，且没有任何预警动作。所以「手牌超过 7 张」在别人的回合是一种**脆弱状态**。

**推论三**：这让「掷骰」这个动作本身带上了攻击性。P 不必说话，只要在某人手牌 9 张时掷骰，就构成威胁。

### 3.3 系统必须支持的提示（机制变了，提示也要变）

v0.2 的提示只是"提醒自己别被炸"。现在还需要**提醒别人可以被炸**——这是两回事。

| 提示 | 位置 | 给谁看 | 说明 |
|---|---|---|---|
| **自己的弃牌风险** | 手牌区旁 | 自己 | 手牌 ≥8 时显示「掷出 7 需弃 N 张」，随交易实时更新 |
| **他人的手牌警示** | 玩家头像旁 | **所有人** | 手牌 ≥8 时数字变警示色（如红描边） |
| **掷骰按钮** | 操作区 | 当前玩家 | 未掷骰时常亮；已掷骰后变灰，但其他动作仍可做 |

> ⚠️ **第二条是本轮新增的，很重要。**
> 「恶意投 7」成立的前提是**决策者知道谁手牌多**。实体桌上这个信息是可见的（你能看到别人手里那一沓牌），线上如果不醒目，机制就退化成"随机攻击"。
> 所以这属于**还原实体桌的可见性**，符合 P4 而不是违反它。

### 3.4 接收方风险

接收方不是无风险的：B 收到牌后如果自己也超过 7 张，掷出 7 时 B 要弃。所以 A 必须分散给多个低手牌玩家。

系统**不做任何约束**——这是玩家的策略空间。

## 4. 交易权限模型（V-3）

### 4.1 谁能和谁交易

| 发起方 | 对象 | 是否允许 |
|---|---|---|
| 当前玩家 P | 任意其他玩家 | ✅ |
| 任意其他玩家 | 当前玩家 P | ✅ |
| 非当前玩家 A | 非当前玩家 C | ❌ **必须经过 P** |

**推导出的玩法**：A 想跟 C 换资源时，必须让 P 做中间人（A→P→C，或 P 协调）。P 因此可以**收取过路费**。这是个很自然的、官方规则下不存在的玩法，且完全符合你的规则表述，系统不需要特殊支持——玩家在语音里谈好，用两次交易执行即可。

### 4.2 交易界面的形态（语音方案下）

因为谈判在语音里完成，界面不需要"广播竞价"，只需要**执行**：

**当前玩家 = 交易所**

```
A、C、D 各自向 P 发交易请求
        ↓
   ┌─────────────────────┐
   │   P 的面板：三条待处理 │
   └─────────────────────┘
        ↓ P 逐个接受 / 还价 / 拒绝
```

- 任何人可向当前玩家发起请求
- 所有请求集中在 P 一处，P 是唯一的裁决点
- 天然串行，不存在并发抢单

> **待裁决**：是否额外保留"挂牌"（广而告之、谁都能接）作为没开语音时的兜底 → **D-01 选项 B**。
> 我的建议是**不做**，详见 `03-trade-and-ux.md` 第 3 节。

### 4.3 成交的原子性

无论哪一方发起，成交都是**双方资源同时转移**，且需要双方确认：

- P 定向发起 → A 接受 → 转移（**A 的接受行为即确认**）
- A 发请求 → P 接受 → 转移（**P 的接受行为即确认**）

任何一方资源不足时，服务端拒绝并给出原因。**转移与扣减是同一原子操作。**

## 5. 借港机制（V-4）

### 5.1 规则

当前玩家 P 的港口，可以被**其他任何玩家借用**，在 P 的回合内执行兑换。

```
C 想用 P 的 2:1 羊港：C 有 3 张羊，想换 1 张矿
→ 正常（C 无此港）只能 4:1，需 4 张羊
→ 借用 P 的港口：只需 2 张羊
→ 差额（2 张羊）是 C 付给 P 的"租金"？还是纯白借？
```

**这里有一个必须你裁决的问题**（Q-02）：

| 方案 | 说明 |
|---|---|
| A | **纯白借**：C 直接享受 P 的港口比例，P 无所得。租金由玩家语音协商后用一笔单独交易支付 |
| B | **系统代收**：C 用 2 张羊换 1 张矿，其中差额自动结算给 P |
| C | **代换模式**：P 手动替 C 执行兑换（P 点操作，扣 C 的资源，给 C 产物），P 无系统层面的收益 |

**我的建议：A + C 组合**——系统只提供「代换」能力（C 或 P 发起，资源从 C 账户扣、产物进 C 账户），租金部分完全交给语音协商（因为租金形式千变万化：可能是资源、可能是口头支票、可能是"下次帮你说句话"）。

**理由**：任何把租金系统化（方案 B）的设计，都会限制玩家的谈判自由度。而这是你们的玩法核心。

### 5.2 代换操作的约束

- 必须由**当前玩家 P** 确认或执行（因为港口是 P 的）
- 被代换者 C 必须拥有该港口对应的资源数量
- 港口比例按 P 的港口计算（不看 C 有没有港口）
- 一个回合内可多次代换，无次数限制

> ⚠️ **漏洞提醒**：如果 P 有 2:1 羊港，C 有 20 张羊，C 可以借 P 的港口把 20 张羊全换成 10 张任意资源。这是否符合你们的预期？如果是，就是合理玩法；如果不是，需要加限制（Q-03）。

## 6. 口头支票（V-7）：明确不做

### 6.1 结论

**系统不实现任何形式的借条、合约、债务记录、承诺追踪。**

### 6.2 理由（你自己给出的，我认为非常正确）

- 资源卡不必展示，所以「我手里没这张牌」无法被验证
- 允许毁约、允许谎称
- 因此任何系统化的债务记录都是**假保障**：它记录了一个无法强制执行的承诺

### 6.3 这条规则的真实后果

这不是「少做一个功能」，而是**把信任变成了游戏资源**：

| 行为 | 短期收益 | 长期代价 |
|---|---|---|
| 收了牌不还 | 白拿资源 | 全桌下次不再与你存牌 |
| 谎称没有某资源 | 保住关键牌 | 交易对手会要求"先给后要" |
| 守信 | 当下无收益 | 成为可被托付的人，获得更多存牌机会 |

**这是一个声誉博弈系统，而且它跑在语音里，不在代码里。** 系统要做的是**不破坏它**——所以绝不能加「交易确认弹窗」"是否确认对方会归还"这类东西。

### 6.4 唯一需要的系统支持

无。交易就是即时资源转移，发生后不可撤销（R-35 保持）。

## 7. 银行无限资源（V-5）

- 银行不设库存上限，任何产出/兑换都能满足
- **作废条目**：`02` 的 R-31（银行不足全有或全无）、R-35（银行 19 张）、R-79（丰饶受存量限制）
- 丰饶卡可无条件取任意 2 张
- 垄断卡照常（取其他玩家全部，不涉及银行）

**副作用**：游戏后期不会出现「资源枯竭」的紧张感。这是取舍，不影响玩法成立。

## 8. 开局选地限时（V-6）

### 8.1 设定

| 项 | 值 |
|---|---|
| 总时长 | **3 分钟**（覆盖全部 8 次放置） |
| 计时起点 | 全员准备完成、地图揭示的瞬间 |
| 计时权威 | 服务端（客户端倒计时只是渲染） |
| 超时处理 | 见 Q-04 |

### 8.2 为什么这个设计是对的

你给出的理由值得记下来：**「在大家审视地图的时候，纷争就已经开始了」**。

这是对的——选地阶段的谈判密度往往高于对局中段，因为此时所有人的资源承诺都还是空头，可以用「以后我给你」来换位置。3 分钟的硬压力会放大这种紧张感，而不是打断它。

### 8.3 UI 要求

- 倒计时常驻显示，最后 60 秒变色
- 剩余放置次数提示（"还剩 3 次放置"）
- 当前轮到谁高亮
- **不做**：任何"推荐位置"提示（D-02 的信息克制原则）

## 9. 这套规则组合产生的涌现玩法

我认为这是文档里最有价值的一节——因为它说明了这个项目**为什么值得做**。

### 9.1 策略层：手牌管理从被动变主动

官方规则下，7 是纯运气。你只能祈祷。你们的规则下，7 变成可管理的风险：

- 在自己回合开始就决定「这轮要留几张牌」
- 决定「存给谁」（分散给低手牌者）
- 决定「存多少」（既要避免弃牌，又不能让对方承担太多风险导致拒收）
- 决定「要不要给分红」（用利息换取对方的保管意愿）

**这已经是一个独立的策略维度，官方卡坦没有。**

### 9.2 社交层：中间人经济

因为「只能与当前玩家交易」，跨玩家交易必须经过当前玩家。这意味着：

- 当前玩家可以**收取过路费**
- 当前玩家可以**拒绝**（"我不帮你们牵线"）
- 有人会为了"被需要"而维持良好关系

官方规则下，当前玩家只是"轮到你了"，你们的规则下，当前玩家是**临时的交易枢纽**。

### 9.3 资产层：港口变成可出租资产

2:1 港口在官方规则里是固定收益。你们的规则下，它可以**出租**：

- 有港口的人可以在自己回合招揽生意
- 借港的定价是浮动的（取决于当时谁最急需）
- 港口位置的价值因此提升

### 9.4 信任层：声誉是唯一资产

这是最深的：**毁约不受惩罚，但会被记住**。而记性是全桌共享的（都是熟人）。

这套系统会自然演化出：
- 声誉好的人更容易借到牌
- 声誉差的人被要求"先给后要"甚至"逐笔结清"
- 极端情况下被联合抵制

**游戏外的东西（朋友关系）成了游戏内的机制。** 这不是缺陷，这是这个变体最迷人的地方。

### 9.5 反霸权：末期结盟

这条来自你的原话：「后期若有发展到遏制不住的人，剩下的人往往会结盟阻止其速胜。此时就出现了赠予牌 / 拒绝交易 / 恶意投 7。」

**这是官方规则下完全不可能出现的玩法**，也是这套变体最重要的战略层。

#### 三种反制手段，全部无需系统支持

| 手段 | 机制 | 系统要做什么 |
|---|---|---|
| **赠予牌** | 零对价把资源给弱者，帮他追赶 | 已支持（Q-07 = 允许） |
| **拒绝交易** | 联合起来不跟领先者做任何交易 | 不需要（点拒绝即可） |
| **恶意投 7** | 在领先者手牌多时掷骰，赌 7 炸他 | 已支持（V-1 时机自由） |

**没有一条需要新功能。** 这是规则设计得好——机制从规则里自然长出来，不是被硬编码进去的。

#### 一个精妙的制衡：领先者可以当"路障"

因为「只能与当前玩家交易」，如果**领先者正好是当前玩家**，联盟内部想调配资源就必须经过他——而他会全部拒绝。

推论：
- 联盟的资源调配**只能在联盟成员的回合进行**
- 领先者的回合，联盟是**被冻住的**

所以这不是「三人围剿一人」，而是**攻守都有武器**：

| 角色 | 武器 |
|---|---|
| 联盟 | **时间**——只要拖住，领先者拿不到新资源 |
| 领先者 | **回合**——轮到他时，联盟内部无法互相输血 |

这个对称性很漂亮，而且完全是从两条规则（只能与当前玩家交易 + 掷骰时机自由）推导出来的，不需要额外设计。

#### 系统绝对不做的事

- ❌ 不做"落后补偿"
- ❌ 不做"限制结盟"
- ❌ 不做"反垄断"检测

任何平衡性干预都会摧毁这套玩法的核心。**这个游戏的平衡靠桌边的社交契约维持，不靠代码。**

### Q-07 裁决记录

你说「交易形式就是交换」，但存牌在系统层面就是零对价转移。这两条本来冲突，现在裁决为**允许零对价**，理由是：

> 「后期若有发展到遏制不住的人，剩下的人往往会结盟阻止其速胜。此时就出现了**赠予牌** / 拒绝交易 / 恶意投 7。」

**赠予牌是反霸权机制的核心手段之一**（见 9.5）。所以零对价不只是存牌的技术需要，它本身就是一个战术动作。

那个我原本担心是"副作用"的东西——能白送资源给落后的人——**不再是副作用，它就是设计意图。**

### Q-04 的三个候选方案

| 方案 | 说明 | 我的看法 |
|---|---|---|
| A | 超时后系统按「合法位置中相邻资源点数最高」自动放置 | 简单，但可能放到玩家不想要的位置，且违背"不推荐落点"原则 |
| B | 超时后每人每次放置限 15 秒，再超时自动放 | 更人性化，实现多一层状态 |
| C | 超时就地结束，未放置的由系统随机放 | 太粗暴 |

**我的建议：B。** 3 分钟总时长对资深玩家足够，但偶尔有人卡住；两级超时既保留了压力，又不至于毁掉一局。

> **D-02 的例外说明**：自动放置必然要用某种"评估函数"选位置，这与「不给推荐」原则矛盾。但它只在超时时发生，且是被动的。我认为可以接受。
