## 当前事实

### 本轮（2026-11-14 第二轮）已实施 F1–F7

- 协议升到 **v4**（不兼容升级；旧客户端由 JOIN 版本校验判 `PROTOCOL_MISMATCH`）。
- **F1 已实现**：新增 `CREATE` 显式创建（原子、创建者即房主）；`JOIN` 只查找已存在房间，不存在回 `ROOM_NOT_FOUND`，创建重名回 `ROOM_EXISTS`。前端 `intent` 区分创建/加入，创建成功后降级为 join，重连绝不重复创建。
- **F2 已实现**：`SET_ROOM_CONFIG` 拆成 `SET_PLAYER_COUNT` / `SET_BOARD` 两条独立意图。改人数按推荐换盘（6–8→扩展、4–5→标准）并重置 `boardChoice=auto`；重复提交相同人数不洗图；地图生成失败时配置/地图/版本/准备**完整回滚**（`commitConfig` 先算后提交）。
- **F5 已实现**：`TRADE_BANK` 严格 4:1（不再因港口降比例）；新增 `TRADE_PORT`（港口边 key + 资源袋 + 收到资源），所有权按港口边端点的己方村庄/城市判定、道路不算；通用港任意混合 3 张、专用港对应 2 张。**删除 `PORT_TRANSFER`** 借港代换（旧命令类型已移除，运行时 `UNKNOWN_COMMAND`）。用户确认边界：严格足额、禁止同类抵扣。
- **F6 已实现**：正式 `panels.ts` 接入两步交易「我想收到 → 我愿给出 → 摘要发送」，含整数滑条、持有量约束、草稿保留、步骤切换不丢草稿；「我想收到」上限固定 99（不按对方隐藏库存）。
- **F3 已实施**：桌面视口（≥1280×720）一律 `landscapeMode=off`，不整页自转、不方向锁、不弹转向提示；低于 1280×720 且非手机显示桌面门槛提示（静态 `#desktop-gate`）。相机缩放/平移/resize/重连/快照校正全部保留。
- **F4 已实施**：数字圆片统一以 `(t.x, t.y)` 为共同中心，纸雕阴影独立绘制（下移 3px）；`#board` 内文字/装饰 `user-select:none`（输入框不受影响）。复验另修两个**既有可读性缺陷**：地形装饰与强盗原本压住数字，现装饰整体缩到下缘环带、强盗移到地块右下角。
- **F7 本地诊断完成、线上部分 BLOCKED**：`randomDice` 两次独立均匀 1–6、无过滤无补偿；12 万样本七频率 0.16776（理论 1/6）、卡方 11.13（df=10）、最长连续未出七 51 次，见 `probe/f7-dice-report.json`。**线上运行中服务的环境变量与二进制版本本轮 BLOCKED**（无平台管理权限，未假装已查）；线上逐次 DICE 对照 NOT_RUN（不在用户正在玩的房间做实验）。
- **F6 隐私疑点**：结构审计与隔离复现均未发现他人手牌种类泄漏（公共视图只有 `handSize`，`makeOffer` 不校验对方库存，成交时才校验）。用户线上现象仍需在隔离房复现，不能据此宣称「已修复」。
