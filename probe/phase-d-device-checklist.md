## 0. 为什么真机不能被浏览器自动化替代

- `Emulation.setDeviceMetricsOverride` 给出的是**真实 CSS 视口**，但它不改变真实设备的
  浏览器生命周期、网络栈、内存回收、安全区、软键盘、触摸驱动与浏览器栏行为。
- `Page.setWebLifecycleState` 可以模拟 frozen/active，但**不等于**真机切到语音 App 后
  被系统挂起、`ws` 半开、或标签被回收后重开。
- 指南 13.3 明确：「真机人工：手感、误触、语音并行、浏览器栏、安全区与键盘，
  这些不由截图测试替代」。本清单就是这一层的执行规格。
- 视频「内置语音不提供、玩家自行后台电话/语音房」（指南 1）决定了这些场景**必然发生**，
  不是边缘用例。

> **禁止事项**：不得把 `node probe/phase-d-browser-verify.mjs --mode=full` 的
> 浏览器模拟结果、jsdom 冒烟、模拟视口截图或自动化测试数量，写进本清单任一行的
> 「真机结论」字段。浏览器结论与真机结论必须分栏记录。

### D1 · iPhone Safari：后台电话/语音房并行后返回前台

- **场景**：轮到自己行动时，接起电话/切进语音 App，保持 20~40 秒后回到 Safari。
- **前置**：房间已开局、当前玩家为被测设备、桌上有 1 条未过期报价、手牌 ≥ 8 张可触发弃牌的余量。
- **步骤**：
  1. 记录切出前的 `window.__hex.view`（回合、当前玩家、资源、强盗任务、报价 ID 与剩余秒数）。
  2. 切到语音 App / 接电话，保持 ≥ 20 秒（覆盖一次 10 秒报价有效期）。
  3. 回前台，观察：连接状态条、`正在核对` 类文案是否消失、是否自动重连拿到权威视图。
  4. 对照服务端房间状态（另一台设备/服务端日志）逐字段核对。
- **预期**：拿到当前权威视图；未过期报价保留、已过期报价显示「已过期」且不可接受；
  **不自动续期**；不自动重放离线期间的建造/接受意图；不永久停在「正在核对」。
- **证据**：录屏（含切出/回前台时间点）、回前台首帧截图、服务端 STATE/WELCOME 日志、
  前后视图字段对照表。
- **结论**：`NOT_RUN — 本会话无真机设备，未执行`
- **关联**：`D06-01` / `D06-02` / `D06-04` / `CASE-18` / `REAL-01` / `EXIT-06`

### D4 · WiFi ↔ 蜂窝网络切换（含半开连接）

- **步骤**：
  1. 在「提交操作后、收到确认前」的窗口切网络（关 WiFi 开蜂窝，或反向），
     观察是否出现「正在核对结果，不会自动重发」且最终能核对结果、**不重复执行**。
  2. 在「提交操作前」切网络，观察点击是否有可见反馈、是否被静默丢弃。
  3. 手动开启飞行模式 10 秒再恢复，观察是否永久停在「正在恢复/正在核对」。
- **预期**：不静默丢操作、不重复成交、有明确超时与连接重建路径；`ws.readyState` 为 OPEN
  不等于已拿到可操作的完整房间状态（指南 10.1）。
- **证据**：网络切换时间点 + 录屏 + 服务端收到的命令计数（验证无重放）+ 房间最终状态。
- **结论**：`NOT_RUN — 本会话无真机设备，未执行`
- **关联**：`D06-02` / `D06-03` / `CASE-17` / `REAL-04`

### D5 · 浏览器标签被系统回收后重开

- **步骤**：切到其他 App 并制造内存压力（多开应用/相机），≥ 60 秒后回到浏览器；
  若标签已重载，用原分享链接重开。
- **预期**：同名重连坐回原座位、拿到 WELCOME 完整快照（含未过期报价、服务端时间、
  本人冷却）；**离线期间的建造/接受报价不自动重放**；过期报价不续期。
- **证据**：重开首帧 + 服务端 WELCOME 日志 + 重开前后座位/资源/报价对照。

  同名重连不是身份凭证（指南 10.3）。
- **结论**：`NOT_RUN — 本会话无真机设备，未执行`

### D6 · 双指手势、拖动阈值与误触手感

- **步骤**（横屏 667×375 与常见横屏各做一轮）：
  1. 单指平移、双指缩放围绕手势中心；缩放后收到他人 STATE 广播，确认镜头不回弹。
  2. 双指结束后抬手，确认**不误选**棋盘位置、不弹建造确认条。
  3. 单指拖动超过 8 CSS px 后抬手，确认**不建造**；阈值附近（6/8/10 px）各试 3 次。
  4. 点击浮层按钮（放大/缩小/回到全局、确认/取消、弃牌加减、强盗玩家选择），
     确认按钮生效且**不顺带选中棋盘位置**。
  5. 点击棋盘密集候选区，确认消歧 A/B 按钮可点、44px 触控目标不误触。
  6. 记录可读性：6/8 概率点、白/橙棋子在浅色地块、长昵称、大资源数。
- **预期**：真机能稳定选中目标，不依靠精细点按；拖动/点击不互相污染。
- **证据**：录屏（手指可见更佳）+ 关键帧 + 每次操作后的 `#board viewBox` / 确认条状态记录
  （可由浏览器脚本辅助读值，但**手感结论必须来自真机**）。
- **结论**：`NOT_RUN — 本会话无真机设备，未执行`

### D7 · 后台超过 10 秒的报价正确过期

- **步骤**：A 向 B 发一条报价 → 立即切后台/锁屏 ≥ 12 秒 → 回前台 →
  检查列表与详情：是否显示「已过期」、原接受按钮是否禁用、是否**不自动跳到下一条**
  把另一条接受按钮顶到手指下（指南 7.4 / 15 §8 复验⑤）。
- **预期**：过期由服务端时钟裁决（10s）；回来不续期、不可成交、不误点；
  冷却 3s 与刷新/重连不绕过冷却一并复核。
- **证据**：服务端 OFFERS 快照时间序列（含 `expiresAt`、`serverTime`、`nextSendAt`）+ 回前台截图 +
  尝试点击过期接受按钮后的服务端拒绝日志。
- **结论**：`NOT_RUN — 本会话无真机设备，未执行`
