# CATAN · 潮汐群岛

本目录是一个独立运行的 React、Vinext 与 Cloudflare D1 示例。请在本目录安装依赖、启动和构建。

这是依据 CATAN 经典基础规则制作的独立网页游戏原型，支持 3–4 人基础局与 5–6 人扩展局。它不是 CATAN 官方产品，不包含《航海家》《城市与骑士》等独立内容扩展，也没有提供说明书中的固定新手地图。

## 桌面操作

设置中的“操作界面”可切换两种模式，并记住本机选择。**仪表盘**保留右侧建造／交易按钮和地图下方的集中牌台；**极简**把出牌提示与资源概览移到右侧，每张已出的牌独立散落在地图上，位置和角度在放置后保持稳定，新增或拿回牌不重新排列其余牌。极简模式仅在桌面有牌时，在牌面上方显示建造／交易圆形入口。该浮动操作栏可拖动，也可拖顶部把手；位置保存在本机，显示区域变化时保持在地图内，展开菜单会自动避让边缘。双击把手或按 Home 可恢复默认位置；聚焦把手后也可用方向键移动。切换界面保留当前桌面牌、报价和待确认建造；两种模式都支持点击或拖回手牌。

资源牌从手牌拖到地图后，直接摆在桌面，不弹出交易表单。桌面牌可拖回手牌，也可点击拿回。摆牌只是本地暂存，服务端不会提前扣除资源；手牌显示的是扣除暂存后的可用数量。

建造入口以圆形扇出呈现道路、村庄、城市、发展卡四个选项。桌面资源达到成本就会点亮对应入口，多余资源不会使入口熄灭；实际放置仍须符合回合阶段、棋子和地图位置规则，受限时会提示原因。棋盘先显示本地预览，点击确认后才正式支付并提交。确认前可以取消、拿回牌或重新选位置。每次确认只扣这一座建筑的费用，剩余牌继续留在桌上，例如 3 木材和 3 砖块可逐次支付三条路，数量依次剩 2/2、1/1、0/0。初始村庄和道路按蛇形顺序逐个预览和确认，确认前可撤销重选。

交易入口提供银行、港口、玩家三种方式，允许一次使用多种资源。银行按每组 4 张同类资源兑换；港口按通用 3:1 或专用 2:1 的完整同类资源组兑换。开启混合港口家规且拥有通用港口时，可任意混合 3 张资源兑换 1 张。

桌面有牌即可打开交易菜单；实际成交仍遵守回合和兑换规则。玩家交易时，点击玩家名字可指定对象，空桌面同样可以唤起谈判，不点名字则发出公开报价。本局已开启赠牌时，空桌可用原有提交按钮发出赠牌请求；未开启时会明确提示需要提供资源。双方各自摆牌并提交报价，随后都需确认，资源才会一次性交换。修改报价或撤回确认会清除双方原有确认，需要重新确认。定向谈判仅双方可见；资源不足与主动拒绝统一显示“资源交换未达成”，不披露对方库存。

掷出 7 时，服务器更新桌面重置标记，所有玩家拿回尚未提交的桌面牌，旧交易会话失效，再按各自应弃数量摆牌。确认弃牌后才真正扣除资源，并播放牌面烧毁效果。

移动强盗先显示本地位置预览，可换地形或撤销，尚不修改局面和手牌。若有多个可偷取玩家，先选择对象，再点击“确认移动并偷牌”；确认后服务器一次性完成移动和随机偷取一张资源，不能撤销。没有可偷资源时只确认移动。

启动页提供创建房间、邀请码加入与本机练习。练习局保存到当前标签页，刷新后可在启动页继续。结算确认后回到启动页。航海日志可独立滚动，查看较早的播报。桌边视角、手牌拖动、掷骰及建造均有对应动画或音效。

## 规则与联机

核心规则包含起始放置、距离规则、资源产出与银行库存、道路／村庄／城市、五类发展卡、强盗与弃牌、玩家交易、银行与港口兑换、最长道路、最大骑士及 10 分获胜。客户端操作由服务端规则引擎验证。

5–6 人局可选现行官方“配对玩家回合”，或历史官方“特殊建造阶段”。配对第二行动者不再次掷骰、不与玩家交易；历史特殊建造阶段只允许建造和购买发展卡，不能交易、打发展卡或在该阶段获胜。

房间可选择 3、4、5 或 6 人，通过 6 位邀请码加入。每位玩家拥有独立身份；人数到齐后由房主开局。D1 保存权威状态，版本校验防止并发覆盖；玩家只能查看自己的资源和发展卡明细。界面约每 1.7 秒同步状态。

正式联机由服务器请求 RANDOM.ORG 的大气噪声随机整数生成两枚六面骰，忽略客户端提交的点数。服务不可用时明确报错，不推进局面，也不回退到另一随机源。本机练习采用浏览器安全随机，不宣称物理真随机。

## 房主可选规则

房主可在创建房间或开局前修改七项规则。对局中，玩家可通过「游戏设置 → 本局规则投票」提交提案，全员同意后生效。

| 规则 | 默认 | 类型 | 效果 |
| --- | --- | --- | --- |
| 友善强盗 | 关闭 | 官方变体 | 保护低于 3 个公开胜利点玩家的建筑周围地形，荒漠除外。 |
| 通用港口混合兑换 | 关闭 | 自定义 | 拥有通用 3:1 港口时，任意 3 张资源可混合兑换；专用 2:1 港不解锁此能力。 |
| 允许撤销建造 | 开启 | 自定义 | 当前行动内撤销仍可逆的建造并退回资源；后续交易、掷骰、打牌或结束行动会关闭旧建造的撤销。 |
| 无限银行 | 关闭 | 自定义 | 产出、海上兑换和丰收不受银行实体卡库存限制，玩家仍须支付费用。 |
| 自由掷骰时机 | 关闭 | 自定义 | 主回合可先交易和建造再掷骰；仍须且只能掷一次，配对第二行动者不掷骰。 |
| 允许赠送资源 | 关闭 | 自定义 | 允许一侧不给资源的玩家交易，仍需双方确认且包含当前行动玩家；不能赠送发展卡。 |
| 弃牌向上取整 | 关闭 | 自定义 | 掷出 7 时，超过 7 张资源者弃掉一半并向上取整；关闭时按官方规则向下取整。 |

## 验收与边界

105 项自动测试覆盖双确认原子交换、修改报价后重新确认、第三人隐私、并发版本保护、掷出 7 的全员清桌及各项变体。类型检查与构建通过。

HTTP 验收脚本覆盖多人建房、加入、起始放置及骰子请求。联机骰子的验证依赖 RANDOM.ORG 可用。

## 本地运行与检查

建议 Node.js 24。进入项目目录后执行：

```sh
npm run install:ci
npm run dev
```

开发地址默认是 `http://127.0.0.1:5173/`。构建与构建后本地预览：

```sh
npm run build
npm start
```

新环境首次启用联机时，需配置 D1 的 `DB` 绑定并应用现有迁移。先构建生成配置，再执行一次：

```sh
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_slippery_ulik.sql
```

不要重复执行已经应用的建表迁移。本地数据库与未来部署的数据库分别管理。

```sh
node --test lib/engine.test.js tests/room-service.test.mts tests/ui-staging.test.mts tests/table-http.test.mts
npx tsc --noEmit
node tests/http-smoke.mjs
```

HTTP 验收需开发服务器运行，会创建测试房间但不打印身份令牌或手牌。可用 `CATAN_SMOKE_URL` 环境变量更换测试地址。桌面交易服务测试使用真实规则与身份校验，只有骰子传输被替换为固定测试结果。

## 增加后续趣味规则

`lib/rule-options.ts` 是共享规则目录，记录名称、说明、默认值、官方／自定义分类和引擎选项。增加条目会接入复选框与服务端白名单，但仅添加复选框不会实现规则。

新增规则还需在 `lib/engine.js` 中保存选项并实现对应分支、合法动作和公开状态；补充引擎、服务与必要的交互测试，并核对界面提示。改变交易或资源规则时，还需检查手牌暂存、报价、隐藏信息和并发行为。
