### 1. 道路偶发不显示 —— 真根因：SVG filter 零宽 bbox

`#soft` 用默认 `filterUnits=objectBoundingBox`。pointy-top 六边形有**垂直边**（两端 x 相同，
`<line>` 几何 bbox 宽度 = 0），滤镜区域 `width="260%"` × 0 = 0 → **整条路被裁掉**，斜边正常，
所以表现为「偶发」。seed-room 挑最远顶点恰好全是斜边，224 个测试才一直没抓到。
修法：`roadMarkup()` 去掉 filter，改用一条下移 2.5px 的深色线做阴影；另加 key 反解兜底
（`pointFromKey` / `roadEndpoints`），任何合法 vertex/edge key 都能落到画布，并对账告警。
新增 `apps/web/test/roads.test.ts` 6 条；真浏览器构造垂直边验证 `renderedRoads=1 filtered=0`。
