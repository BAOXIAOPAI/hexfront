## 这一版验证了什么

- **同一局状态**：第 14 回合、甲行动、9 张手牌（掷 7 需弃 5）、丙/丁两条并存提议、强盗在北岸 6 号田、四名玩家均有公开建筑与成就。
- **五个状态**：普通对局、交易第一步（我想收到）、交易第二步（我愿给出）、收到的提议、弃牌与强盗。掷骰子在 B 原型里演示 7 点，会自然进入弃牌流程。
- **交易重做**：两步图形选择，滑条 + 加减 + 数字输入；对象与摘要常驻；“发起交易 / 收到的提议 (N)”切换不丢草稿；发送后显示条件、倒计时、冷却、撤回。
- **玩家第二通道**：建筑屋顶带玩家名字首字，道路中心线按玩家使用不同虚线；黄色玩家改为更深的赭黄并加粗道路描边，和黄麦田分开。
- **主设计视口** 1440×900 与 **最低支持视口** 1280×720 均无页面滚动；五个状态的手牌、确认按钮、报价和当前任务完整可见。另检查 1366×768 不溢出。
- **可点击**：
  - 悬停地块看地形/点数/强盗说明；
  - 点玩家、资源、发展卡看公开/私有信息；
  - 接受或拒绝提议，资源即时变化；
  - 掷骰（B 原型演示 7 点，报价清空并进入弃牌；A 历史版仍是 11 点）；
  - 交易：选对象 → 选我想收到（滑条/加减/数字）→ 下一步选我愿给出 → 看完整条件直接发送；
  - 报价：切换“收到的提议 (N)”，接受/拒绝；新报价只更新数量，不抢焦点、不丢草稿；
  - 港口 2:1 兑换；银行 4:1 显示不可用原因；
  - 建造：道路/村庄在棋盘上出现金色可建位置，选中后确认，资源扣除并落到棋盘；
  - 发展卡：点开牌堆购买 1 张，播放抽卡动画；发展卡数量与日志更新；
  - 弃牌：掷出 7 后报价清空，点手牌选满 5 张（显示持有/已选，可点徽章取消），确认后等待丙弃牌，再选地块放强盗并选对象抽 1 张；
  - 强盗阶段：弃完但未结算时建造/交易/兑换恢复，发展卡/结束回合仍锁定；抽牌播放背面卡飞行动效；
  - 缩放按钮、Esc 关闭浮层、帮助、日志、结束回合确认。

## 已知边界（原型，不是正式实现）

- 没有服务端；发送成功、报价计时、冷却、丙的弃牌与抽牌内容都是本地演示。
- 报价倒计时只在交易面板打开时推进，关闭后暂停；新报价模拟在首次打开交易后 8.5 秒出现一次。
- 结束回合只做确认提示，不切到下一家的完整对局状态。
- 购买发展卡是本轮新增的本地演示动作；不改变三个核心状态，也不代表正式规则已接入。
- 建造只演示道路与村庄的合法落点；城市因为当前矿石不足而禁用，升级流程待正式状态。
- 地块/边/点的可建位置是 SVG 点击层，尚未做键盘逐点 Tab 导航；弃牌徽章是演示用嵌套 span，正式实现需要拆成独立按钮。
- 字体使用 macOS 系统字体回退（PingFang SC / Avenir Next；A 历史页用 Songti）。正式实现需按设计规范引入 Noto Sans SC + Inter 与失败回退。
- 不包含手机、平板适配；当前只对 1280×720 及以上桌面视口做设计。
- 对照页与原型均为设计评审材料，不是营销首页，也不是正式游戏入口。

## 设计意图

### A · 航海图志

把对局做成一张摊开的航海底图：水彩地块、墨线海岸、数字圆片像盖在纸上的印章；界面是羊皮纸、黄铜和黄红图章。信息更像批注和航海记录，安静、耐看、有档案气。

### B · 晴湾纸雕

把对局做成一盒层叠纸雕桌游：每块地形是一张纸，树、羊、山有厚度；海面是丝网印波纹。界面是厚卡片、圆角、彩色顶条和可按下去的实体按钮。更亮、更亲近、更像朋友围坐的桌面。
